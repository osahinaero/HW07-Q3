Stern–Gerlach Analyzer Simulator

Silver atoms (spin ½). Choose an initial polarization, configure 1–3 analyzer axes, and select which channel continues to the next stage. Only surviving atoms reach downstream analyzers. Angles are measured from +z toward +x.

Outcomes

Quantum probabilities: P(+ | spin s along prior axis) = [1 + s cos(θ − θ₀)] / 2. Each measurement resets the spin state to the selected ± eigenstate. Counts are sampled using pseudorandom numbers. For reproducible comparisons, use the exact analytical probabilities shown in the table rather than expecting simulated counts to match exactly.
